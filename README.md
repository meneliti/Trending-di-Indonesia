## 📖 Keterangan Kolom

- **Tren** — kata kunci yang sedang banyak dicari di Google Indonesia
- **Volume Penelusuran** — estimasi jumlah penelusuran (rb+ = ribuan, jt+ = jutaan)
- **Kenaikan** — persentase lonjakan volume dibanding periode sebelumnya
